About this repository

This site hosts the reports and Jupyter notebooks produced for COMPSCI 361 — Machine Learning at the University of Auckland. It is intended as a personal portfolio of academic work, covering the end-to-end machine-learning workflow: data exploration, feature engineering, model training, evaluation, and critical analysis.

Every assignment is available as a self-contained HTML report that can be viewed directly in the browser — no setup required. The original Jupyter notebooks are also provided in the GitHub repository for full reproducibility.
